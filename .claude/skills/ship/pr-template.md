# PR template for `/ship`

Title: the main commit's Conventional Commit line, with the ticket code at the
end, e.g. `fix(mobile): show earned trophy icons [B1]`.

Body, in English, written for a reviewer who has not seen the session:

```markdown
## Summary

<what changes and why, 2–4 lines>

Ticket: <Notion URL>

## Acceptance criteria

- [x] <criterion> — <proof: test name, command, screenshot>
- [ ] <criterion left open> — <why>

## Decisions and trade-offs

<choices made during the work and what was rejected; "None" if none>

## Not done

<unverified items, follow-up tickets created (with links); "Nothing" if none>

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

Attach screenshots of changed UI under the criterion they prove.
